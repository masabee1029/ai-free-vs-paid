# AIの無料と有料くらべ

https://masabee1029.github.io/ai-free-vs-paid/

- `content/*.md` … 記事（書式は build.py の先頭）
- `python3 build.py` … docs/ を生成（GitHub Pages は main:/docs）
- `site.json` … サイト名・色・おすすめ商品（カテゴリ: ChatGPT / Gemini / Claude / Copilot / NotebookLM / Canva / 比較）
- `topics.txt` … 自動投稿の記事ネタ
- 料金・上限は毎月1日の定期作業 ai-free-vs-paid-monthly が公式情報で確かめ直す
