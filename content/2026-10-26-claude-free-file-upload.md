会議のPDFや、ホワイトボードを撮った写真を、そのままClaudeに読んでもらえたら楽ですよね。
結論から言うと、Claude無料版でもファイル・画像は読めます。公式ヘルプには、PDF・DOCX（Word）・XLSX（Excel）・CSV・TXTなどの文書と、JPEG・PNG・GIF・WebPの画像を添付でき、1つのチャットに20ファイルまで、1ファイル500MBまで、PDFは1,000ページまで、と書かれていて、無料と有料で分ける記述はありません。
無料と有料で違いが出るのは、読ませたあとに「どれだけ往復できるか」の使用量と、使えるモデル・プロジェクトの数のほうです。この記事では、公式ヘルプと料金ページで確かめた内容を、会社員のあなたの使い方に沿って整理します。

**確認日：2026年10月26日**（料金・上限は各社の公式情報で確認。変わることがあります）

## Claude無料版で読めるファイルと画像｜公式ヘルプの形式と上限

2026年10月26日に、Claudeヘルプセンターの「アップロードできる文書の種類」の記事で確かめた内容を表にしました。この記事には、プラン別の記載がなく、無料・有料に共通の上限として書かれています。

| 項目 | 公式ヘルプの記載 |
|---|---|
| 文書の形式 | PDF・DOCX・CSV・TXT・HTML・ODT・RTF・EPUB・JSON・XLSX（XLSXは、コード実行とファイル作成の機能を有効にしたアカウントで） |
| 画像の形式 | JPEG・PNG・GIF・WebP |
| 1ファイルの容量（チャットに添付） | 500MBまで |
| 1つのチャットに添付できる数 | 20ファイルまで |
| 画像の大きさ | 8000×8000ピクセルまで |
| PDFのページ数 | 1,000ページまで |
| プロジェクトに入れるファイル | 1ファイル30MBまで。数の上限はなく、合計がコンテキストウィンドウ（一度に読める量）に収まる範囲 |

数字だけ見ると「十分すぎる」と感じますよね。読ませ方で差が出るのは、次の3点です。

- **PDFは100ページ以下なら、文字と図・グラフ・画像の両方を読みます**。101〜1,000ページは文字だけで、図は読まれません
- **Word・Excelなどの文書は、文字だけを抜き出します**。文書の中に貼った図や写真は読まれないので、図を見せたいときは画像として別に添付します
- **画像は1,000×1,000ピクセル以上がすすめられています**。小さい画像や、ぼやけた写真は読み取りが落ちます

会社の資料に当てはめると、「10ページの会議資料PDF」「ホワイトボードの写真」「見積書をスキャンしたPDF」は、どれも無料版の範囲に入ります。工程表を撮った写真も、文字が読める大きさで撮れていれば読み取れます（執筆時点の公式ヘルプの記載にもとづきます。読み取りの精度は写真の写り方で変わります）。

## 無料と有料でファイルの扱いはどう違う？

ファイルの形式・容量・数は共通の記載で、違いは「読ませたあと」に出ます。料金ページとヘルプで確かめた内容を並べました。

| 項目 | 無料（Free） | 有料（Pro） |
|---|---|---|
| 料金 | 0ドル | 月20ドル（年払いは200ドルの前払いで、月17ドル相当） |
| ファイル・画像の添付 | できる（形式・容量・数の上限は共通の記載） | 同じ |
| 読ませたあとの使用量 | ふだんの質問をこなせる量。5時間ごとの枠で回復 | 5時間あたり無料の少なくとも5倍。週の上限も加わる |
| 使えるモデル | Sonnet・Haiku | Opus・Sonnet・Haiku |
| プロジェクト（資料をまとめて置く箱） | 5つまで | 上限の数の記載なし |
| 一度に読める量（コンテキストウィンドウ） | 無料版の数字はヘルプに記載なし | 最新のモデルで最大100万トークン、ほかのモデルは50万か20万トークン |
| 上限に当たったとき | 回復を待つ、またはプランを上げる | 回復を待つ、または使用量クレジット（標準のAPI料金で続ける仕組み）を使う |
| Claude Code・リサーチ機能 | なし | あり |

「トークン」は、AIが文章を数える単位です。読ませた資料の文字も、あなたの質問も、Claudeの返事も、すべてトークンとして数えられます。

つまり、無料版で「PDFが読めない」ことはなく、起きやすいのは「読ませたあと、何往復かすると上限の表示が出る」ことです。あなたの使い方が「週に数回、1本の資料を読ませて2〜3回質問する」なら無料で足り、「毎日、長い資料を何本も読ませて何度も聞き直す」なら有料が向きます。あなたの1週間は、どちらに近いでしょうか。

無料と有料の全体の違いは、[Claudeの無料と有料の違い｜Proにすると何が変わる？](claude-free-vs-paid.html)にまとめています。

## 上限の考え方｜「ファイルの上限」「長さの上限」「使用量の上限」は別もの

ファイルを読ませるとき、上限は3つの層に分かれています。ここを分けて考えると、「どこで止まったか」が分かり、対処が決まります。

| 上限の種類 | 何を数えるか | 当たったときの表示の例 | 対処 |
|---|---|---|---|
| ファイルの上限 | 1ファイルの容量、数、ページ数、画像の大きさ | 添付できない、ファイルが大きすぎる | ファイルを分ける、画像を縮める |
| 長さの上限 | 1つの会話に入っている文字と資料の合計（コンテキストウィンドウ） | 会話が長すぎる | 新しい会話を始める、必要な部分だけ貼る |
| 使用量の上限 | 5時間ごとの枠で使った量（会話の長さ・モデル・機能で変わる） | 使用量の上限に達しました | 回復を待つ、新しい会話で続ける、プランを上げる |

印刷の現場に例えると、ファイルの上限は「給紙トレイに入る紙の枚数」、長さの上限は「1冊に綴じられるページ数」、使用量の上限は「印刷機の1日の稼働量」です。トレイに紙が入っても、1日の稼働量を超えれば止まります。

ファイルを読ませるときに大事なのは、**資料は1回読ませたら終わりではなく、返事のたびに読み直されている**ことです。公式ヘルプには、長い会話ほど使用量を多く使うと書かれています。300ページのPDFを入れて10回質問すると、10回ぶん、長い会話として数えられます。

私も最初は、資料をまるごと入れるほうが親切だと思って、上限に早く当たるところでつまずきました。公式ヘルプの節約のコツは、会社の資料にそのまま置き換えられます。

- **必要な部分だけ読ませる**：100ページの仕様書なら、今日の質問に関わる章だけを別のPDFにして渡します
- **1つの資料につき1つの会話にする**：「会議資料の要約」と「見積書の確認」は別の会話にします
- **質問を1回にまとめる**：「決まったこと」「宿題」「期限」を、1回の依頼に並べて書きます
- **使わない機能は切る**：Web検索や、つないだアプリが不要なときはオフにします。ヘルプには、拡張思考（じっくり考えるモード）を切る、努力レベルを下げる方法も案内されています
- **プロジェクトの使わない資料は外す**：プロジェクトに入れた資料も、会話のたびに読まれます

無料版の使用量の仕組みは、[Claude無料版の制限と上限｜メッセージ数の考え方](claude-free-limits.html)にくわしくまとめています。

## 会社の資料を読ませる前に｜向かない人・注意点

便利なぶん、先に確かめておきたいことがあります。

まず、会社の決まり（AIの利用規程、情報の持ち出しのルール）で、Claudeに資料を入れてよいかを確かめてください。許されている場合でも、社外秘とお客さまの個人情報は入れない、という線引きを守ると安心です。見積書をスキャンしたPDFには、取引先の名前・担当者名・金額が入っています。読ませる前に、名前を消すか、数字をダミーに置き換える一手間が、あなたを守ります。個人向けプランには、会話を学習に使うかどうかに関わるプライバシーの設定があるので、使い始める前に設定画面を一度開いて確かめておくと落ち着きます。

次に、無料版が向かない使い方です。

- **毎日、長い資料を何本も読ませて、何往復も聞き直す人**：使用量の枠に先に当たりやすく、待ち時間が仕事の流れを切ります。この使い方なら、Proを検討する材料になります
- **Excel（XLSX）をそのまま読ませたい人**：コード実行とファイル作成の機能を有効にする必要があると書かれています。設定に不安があれば、CSVやPDFに書き出して渡すほうが早いです
- **Wordの中の図や写真を見せたい人**：PDF以外の文書は文字だけが読まれます。図は画像として別に添付するか、PDFにして渡します
- **101ページを超えるPDFの図やグラフを読ませたい人**：101〜1,000ページは文字だけになります。図のあるページだけ抜き出すと読めます
- **最上位のモデル（Opus）で読ませたい人**：無料版はSonnet・Haikuの記載です

39歳の会社員の方なら、こんな声になるかもしれません。「工程表の写真を撮って、遅れている工程だけ拾ってもらえたら、夜の集計が要らなくなるんですけど、会社の数字を入れていいのか不安で」。その不安は正しいです。順番は、①会社の決まりを確かめる、②自分で作ったダミーの工程表で試す、③許された範囲の資料だけ本番で使う、で十分です。無料版は、①と②を試す場所としてちょうどよい大きさです。

## 今日試せる、ファイルと画像の3つの頼みごと

無料版で、会社の決まりの範囲で試しやすい頼みごとを3つ選びました。どれも、1つの会話に1つのファイルで、質問は1回にまとめます。

1. **10ページ以内の会議資料PDF**：「この資料から、決まったこと・宿題・期限を、担当者ごとに箇条書きにしてください」と頼みます。100ページ以下なので、図やグラフも読まれます
2. **ホワイトボードの写真（JPEG・PNG）**：「写真の文字を起こして、項目ごとに並べてください。読めない字は［不明］と書いてください」と頼みます。文字が読める大きさで、まっすぐ撮るのがコツです
3. **ダミーの数字にした工程表（CSV）**：「予定日を過ぎている行だけ抜き出して、遅れの日数の順に並べてください」と頼みます。本番の前に、作り方を覚える練習になります

この3つで、「読める」「どこまで読めるか」「どのくらいで上限に近づくか」の感覚がつかめます。残業を30分減らす一歩は、この練習の1回から始まります。

紙の資料が多い職場なら、スキャナーで一度PDFにしておくと、Claudeに読ませるのも、社内で探すのも早くなります。頼み方の型を1冊で学ぶなら、Claudeの解説書も助けになります。

## まとめ

Claude無料版でも、ファイルと画像は読めます。上限は「読ませたあと」に出てきます。

- 公式ヘルプの記載では、PDF・Word・Excel・CSVなどの文書と、JPEG・PNG・GIF・WebPの画像を、1つのチャットに20ファイル、1ファイル500MB、PDFは1,000ページまで添付でき、無料と有料で分ける記述はない
- PDFは100ページ以下なら図も読み、Word・Excelは文字だけ。図は画像として別に渡す
- 無料と有料の違いは、読ませたあとの使用量（Proは5時間あたり無料の5倍以上）、モデル、プロジェクト数
- 上限は「ファイル」「長さ」「使用量」の3層。資料は返事のたびに読み直されるので、必要な部分だけ、1資料1会話が節約のコツ
- 会社の資料は、会社の決まりを確かめ、社外秘と個人情報を消してから

まずは、10ページ以内の会議資料を1本、新しい会話に添付して、1回だけ頼んでみませんか。あなたが最初にClaudeに読ませたい資料は、どれでしょうか。
