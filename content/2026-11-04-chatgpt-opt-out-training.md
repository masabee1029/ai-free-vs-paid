会社の資料をChatGPTに貼る前に、「これ、AIの学習に使われないかな？」と手が止まったこと、ありますよね。
結論から言うと、**ChatGPTに学習させない設定は、無料版でもできます**。「設定」→「データコントロール」→「すべての人のためにモデルを改善する」をオフにするだけで、OpenAIの公式ヘルプには、オフにすると新しい会話はモデルの学習に使われない、と書かれています。履歴を残したまま使えるのも安心なところです。
この記事では、あなたが今日5分で設定を終えられるように、公式ヘルプで確かめた手順と、無料版と有料版で何が違うのかを表でまとめます。

**確認日：2026年11月4日**（料金・上限は各社の公式情報で確認。変わることがあります）

## ChatGPTに学習させない設定｜無料版での手順

まずは手順からです。2026年11月4日にOpenAIヘルプセンター（日本語版）で確かめた画面の名前を、そのまま書いています。

**パソコン（ブラウザでサインインしているとき）**

1. 画面のアカウントメニューを開きます
2. 「設定」を選びます
3. 「データコントロール」を選びます
4. 「すべての人のためにモデルを改善する」を選んでオフにし、「完了」を選びます

**スマホ（iPhone・Androidのアプリ）**

1. サイドバーを開きます
2. プロフィールのアイコンを選んで、設定を開きます
3. 「データコントロール」を選びます
4. 「すべての人のためにモデルを改善する」をオフにします

公式ヘルプによると、**サインインしていれば、この設定はアカウント全体に効きます**。パソコンでオフにすれば、スマホのアプリでも同じ扱いになるということです。通勤中にスマホで聞いて、会社でパソコンの続きを作る、という使い方でも1回の設定で済みます。
サインインせずに使っているときは、「設定」で同じ項目をオフにでき、その選んだ内容は使っているブラウザに保存される、と案内されています。

ここで知っておきたいのは、公式ヘルプに**無料版・Plus・Proの個人向けの使い方では、データの共有は最初から「オン」になっている**と書かれていることです。何もしなければ学習に使われる側の設定になっているので、まだ触っていないなら、今日オフにしておくと安心です。

## オフにすると何が変わる？｜履歴・メモリとのちがい

「オフにしたら、今までのチャットが消えるのでは？」という心配もよく聞きます。公式ヘルプで確かめた内容を表にしました。

| 気になること | 公式ヘルプの説明 |
|---|---|
| 新しい会話 | OpenAIのモデルの学習に使われない |
| 今までのチャット履歴 | 消えない・隠れない。通常のチャットは履歴に残る |
| アーカイブしたチャット | アーカイブのまま。アーカイブしても学習に使うかどうかは変わらない |
| プロジェクトのチャット | それぞれのプロジェクトに残る |
| メモリ（あなたの好みを覚える機能） | 学習の設定とは**別の設定**。オフにしてもメモリはそのまま |
| 音声モード | 学習に使うかどうかは**別に設定**がある |

表で大事なのは、**「学習させない」と「メモリを切る」は別物**ということです。メモリは、ChatGPTがあなたに合わせた返事をするための機能で、学習の設定はOpenAIのモデルをよくするために使うかどうかの設定です。片方を切っても、もう片方は変わりません。

もう1つ、見落としやすい点があります。公式ヘルプには、**学習をオフにしたあとでも、返事に「いいね」「よくないね」を押すと、その会話全体が学習に使われることがある**と書かれています。会社の資料を扱った会話では、評価のボタンは押さないでおくと安心です。

## 一時チャットの使い方｜履歴に残したくない日に

「設定はそのままで、今日のこの1回だけ残したくない」というときは、一時チャットが便利です。公式ヘルプで確かめた始め方は次のとおりです。

1. 新しいチャットを開きます
2. 「一時チャット」を選びます
3. 最初のメッセージを送る前に、「パーソナライズあり」か「パーソナライズなし」を選びます
4. メッセージを入力します

一時チャットと通常のチャットのちがいを並べました。

| 項目 | 一時チャット | 通常のチャット |
|---|---|---|
| 履歴 | 保存しない限り、履歴に出ない | 削除するまで履歴に残る |
| 学習 | 一時チャットのあいだは、モデルの改善に使われない | 「すべての人のためにモデルを改善する」の設定に従う |
| メモリ | 新しく作ったり、更新したりしない | メモリがオンなら使ったり作ったりする |
| 保管 | 安全のため、コピーが**最長30日間**保管されることがある | 保存したチャットの決まりに従う |

注意したいのは、**一時チャットを「保存」すると、通常のチャットに変わる**ことです。保存した時点から、あなたのアカウントの学習の設定が当てはまります。また、30日間はOpenAI側に安全のための保管がありうるので、「一時チャットなら社外秘を入れても大丈夫」という意味ではありません。

## 無料版と有料版・会社向けで何が違う？

「有料版にすれば、学習されないのでは？」と考える人もいます。公式ヘルプとOpenAIのエンタープライズプライバシーのページで確かめると、分かれ目は**値段ではなく「個人向けか、会社向けか」**でした。

| 項目 | 無料版・Plus・Pro（個人向け） | Business・Enterprise（会社向け） |
|---|---|---|
| 最初の状態 | データの共有は**オン**（学習に使われる側） | 最初から**学習に使われない** |
| 学習をオフにできる？ | できる（「すべての人のためにモデルを改善する」） | もともと使われない |
| 一時チャット | 使える | 使える（会社の保管の決まりも当てはまる） |
| 自分でデータを書き出す・アカウントを消す | 設定からできる | 自分ではできず、ワークスペースの管理者に頼む |
| 会社としての管理 | なし（自分で設定する） | 保管期間・メモリ・アクセスなどを会社側で設定できる |

公式ヘルプの一文には、最初にデータ共有がオンになっているプランとして「無料版・Plus・Pro」が書かれていて、安い有料プランのGoの名前はありません。Goを使っている人は、「設定」→「データコントロール」の画面で、いまの状態を自分の目で確かめておくのが確実です。
料金ページの比較表にも、個人向けプランの「プライバシー」の欄に「学習への利用を拒否可能」と書かれています。料金そのものは、[ChatGPTの料金プランの比較](chatgpt-plans-price.html)や、会社で入れるなら[ChatGPT Businessの料金](chatgpt-business-price.html)を見てください。

あなたの使い方なら、どちらが合うでしょうか。自分のアイデア出しやメールの言い回しなら、個人向けで学習をオフにする形で十分なことが多いです。部署で工程表や品質の資料を扱うなら、会社が契約する会社向けプランのほうが、管理の面で話が早くなります。

## 向かない人・注意点｜会社の情報を守るために

学習をオフにするのは大事な一歩です。一方で、次の点は設定だけでは解決しません。

- **「学習されない＝何を入れてもよい」と考えている人**：学習の設定は、OpenAIのモデルの改善に使うかどうかの話です。会社の決まり（情報の持ち出し・AIの利用規程）を先に確かめ、社外秘・顧客の名前・個人情報は、会社が認めていないアカウントには入れないのが安心です
- **一時チャットなら残らないと思っている人**：安全のために最長30日間コピーが保管されることがある、と公式ヘルプに書かれています
- **評価ボタンをよく押す人**：学習をオフにしていても、「いいね」「よくないね」を押した会話は学習に使われることがあります
- **会社のアカウントで使っている人**：会社向けプランでは、設定を変えられるかどうかが管理者の決まりで制限されることがあります。分からないときは、情報システムの担当に聞くのが近道です

工程表や会議メモを扱うときは、品番・取引先名・人の名前を「A社」「製品X」「担当者1」のように置きかえてから貼るだけでも、ずいぶん安心して使えます。

最初は誰でも「とりあえず貼ってみよう」でつまずきがちです。設定をオフにして、置きかえてから貼る。この2つで、浮いた時間を家族との時間に回しやすくなります。

## まとめ

- ChatGPTに学習させない設定は**無料版でもできる**。「設定」→「データコントロール」→「すべての人のためにモデルを改善する」をオフ
- 無料版・Plus・Proの個人向けは、**最初は学習に使われる側（オン）**。サインインしていれば、1回の設定でパソコンとスマホの両方に効く
- オフにしても**履歴は消えない**。メモリや音声モードは別の設定。評価ボタンを押した会話は学習に使われることがある
- 一時チャットは、履歴に残さず学習にも使われない。ただし**最長30日間**の安全のための保管がありうる
- Business・Enterpriseなどの会社向けは**最初から学習に使われない**。会社の資料は、会社の決まりを先に確かめ、社外秘・個人情報は入れない
